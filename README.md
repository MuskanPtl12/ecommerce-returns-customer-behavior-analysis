# E-Commerce Returns & Customer Behaviour Analysis

## Project Overview
An end-to-end data analytics project focused on understanding e-commerce product returns, customer purchasing behaviour, refund impact, and delivery performance.

The project aims to identify return patterns, understand customer behaviour, evaluate financial impact, and uncover operational factors associated with product returns.

## Business Problem
E-commerce businesses face challenges related to product returns, customer satisfaction, refund costs, and delivery operations.

This project investigates why products are returned, which products and customer segments contribute most to returns, and how returns affect business performance.

## Project Objectives
- Analyze overall product return trends and patterns.
- Understand customer return behaviour.
- Identify products and categories with high return rates.
- Evaluate refund amounts and financial impact.
- Explore the relationship between delivery performance and product returns.
- Generate actionable business insights.
